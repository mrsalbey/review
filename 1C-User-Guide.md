

## Первоначальные настройки конфигурации

1. Настройка каталога для выгрузки xml-файлов производится в разделе *Настройки - Каталог XML* .
2. Настройка версионирования объектов предустановлена и выполняется посредством объектов БСП.


## Управление информационными базами

В справочнике *Информационные базы* хранится произвольный список информационных баз 1С. Для каждой базы необходимо указать каталог информационной базы и тип, а также, можно указать версию платформы для открытия пользователя.

![Pasted image 20250625121238](https://github.com/user-attachments/assets/ffeb9f13-0457-4b3f-9cee-ec0a400f8d62)


Форма списка справочника поддерживает следующие команды:
1. Открыть выделенную базу в режиме *Конфигуратор*.
2. Открыть в режиме *1С:Предприятие*.
3. Загрузить файл *.zip* или *.dt* в выделенную базу.
4. Выгрузить файл `ConfigDumpInfo.xml` в каталог для выгрузки xml-файлов, указанный в константе *Каталог XML (меню - Настройки)* .

### Открытие базы в режиме Конфигуратора

Выделенная в списке база будет открыта в режиме *Конфигуратор*.

### Открытие базы в режиме 1С:Предприятия.

Выделенная в списке база будет открыта в режиме *1С:Предприятие*.

### Загрузка архивной копии в базу.

- Можно загружать выгрузку как в файлах *.zip*, так и в *.dt*.
- При загрузке архива в формате *.zip* будет создан временный каталог с наименованием `Review_<uuid>`, в который будут разархивированы файлы из архива. 
- Затем будет предложен выбор файла из архива для загрузки в информационную базу.
- После окончания загрузки временный каталог будет удален.

### Выгрузка файлов конфигурации.

- Операция аналогичная типовой *Выгрузить конфигурацию в файлы*, с одним отличием — выгружается только один файл `ConfigDumpInfo.xml`, содержащий *uuid* конфигурации и объектов метаданных.
- XML-файл выгружается в каталог, указанный в константе *Каталог XML*.
- Выгружаемый файл перезаписывается, либо удаляется после дальнейшей обработки (см. Управление проектами).
