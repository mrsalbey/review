	- [ ] Заголовок отчета соответствует техническому заданию, а именно, *Движение наличных денег*.
	- [ ] Отображение шапки отчета соответствует макету, в частности, *Банковский счет/касса*.
	- [ ] В параметрах запроса виртуальной таблицы стоит отбор по типу денежных средств *Наличные*.
	- [ ] Результат отчета сворачивается по значению первой группировки, то есть по кассе.
2. Отчет по безналичной оплате.
	- [ ] Использован стандартный период и корректно настроено заполнение параметров начала и конца периода.
	- [ ] Заголовок отчета соответствует техническому заданию, а именно, *Отчет по безналичной оплате*.
	- [ ] Результат отчета сворачивается по значению первой группировки, то есть по эквайринговому терминалу.

	- [ ] Добавлена и корректно заполняется группировка *Срок годности*.
	- [ ] В запросе выбраны только те поля, которые необходимы для вывода или настройки отчёта. Например, не указано поле *Тип номенклатуры*.
	- [ ] Не указаны параметры виртуальной таблицы — *Начало периода* и *Конец периода*.
	- [ ] Использован стандартный период и корректно настроено заполнение параметров начала и конца периода.

## Документы

1. Запись клиента.
	- [ ] При записи документа с незаполненной табличной частью НЕ возникает синтаксическая ошибка.
	- [ ] НЕ формируется движение по регистру *Заказы клиентов* при незаполненной табличной части, либо при нулевом значении реквизита *Сумма документа*.
	- [ ] Отсутствует функционал по установке реквизита *Услуга оказана* в предопределенной процедуре модуля объекта `ПередЗаписью()`. Перенесен в реализацию.
	- [ ] Реквизиты *Дата окончания записи* и *Услуга оказана* недоступны для ручного изменения.
	- [ ] Реквизит *Дата окончания записи* рассчитывается автоматически как *Дата начала записи* плюс длительность услуг из табличной части.
2. Реализация товаров и услуг.
	- [ ] Контроль оказания услуги выполняется в обработке заполнения. Отмена создания документа выполняется через вызов исключения.
	- [ ] Запрос оптимизирован. В тексте запроса отсутствуют неиспользуемые поля и источники запроса.
	- [ ] В сообщении пользователю выводится представление ссылочного поля результата запроса.
	- [ ] Установка реквизита *Услуга оказана* записи клиента выполняется при записи реализации при условии, что заполнено значение документа-основания.
	- [ ] При открытии документа в предопределенной процедуре  `ПриСозданииНаСервере()` устанавливается значение реквизита *Признак оплаты* — в значение *Не оплачен*, если создается новый документ и в значения *Не оплачен, Оплачен частично*, либо *Оплачен полностью* — если открывается ранее записанный документ. Проверка выполняется при условии, что признак оплаты не равен значению *Оплачен полностью*.
3. Поступление денежных средств.
	- [ ] При создании документа выводится сообщение в случае, когда реализация уже оплачена. Документ не создается.

## Обработки

1. Монитор руководителя.
	- [ ] Обработка добавлена в раздел *Продажи*. Выводится на главной странице для пользователей с ролью *Руководитель*.
	- [ ] Блоки показателей имеют одинаковую высоту и ширину. Текст в блоках выровнен по центру и выделен жирным шрифтом. Блоки равномерно растягиваются во всю ширину формы при увеличении формы до полноэкранного размера.
	- [ ] Виды диаграмм соответствуют макету, то есть *не объемные*, кроме крайней слева.
2. Планирование загрузки сотрудников.
	- [ ] Планировщик добавлен в раздел *Продажи*. Выводится на главной странице для пользователей с ролью *Администратор*.
	- [ ] При создании документа *Запись клиента* из обработки корректно заполняются реквизиты *Сотрудник* и *Дата начала записи*. Дата и время создаваемого документа текущее.
	- [ ] При изменении варианта периода _День_, _Неделя_, _Месяц_ изменяется временная шкала на форме.
	- [ ] После создания документа записи клиента из формы планировщика, созданный документ отображается на форме планировщика.
	- [ ] Цветовая индикация записей соответствует техническому заданию.
