1. Запись клиента.
	- [ ] Не формируется движение по регистру *Заказы клиентов* при незаполненной табличной части, либо при нулевом значении реквизита *Сумма документа*.
	- [x] Отсутствует функционал по установке реквизита *Услуга оказана* в предопределенной процедуре модуля объекта `ПередЗаписью()`. Перенесен в реализацию.
	- [ ] Реквизиты *Дата окончания записи* и *Услуга оказана* недоступны для ручного изменения.
	- [x] Реквизит *Дата окончания записи* рассчитывается автоматически как *Дата начала записи* плюс длительность услуг из табличной части.
2. Реализация товаров и услуг.
	- [x] Контроль оказания услуги выполняется в обработке заполнения. Отмена создания документа выполняется через вызов исключения.
	- [x] Запрос оптимизирован. В тексте запроса отсутствуют неиспользуемые поля и источники запроса.
	- [ ] В сообщении пользователю выводится представление ссылочного поля результата запроса.
	- [x] Установка реквизита *Услуга оказана* записи клиента выполняется при записи реализации при условии, что заполнено значение документа-основания.
	- [x] При открытии документа в предопределенной процедуре  `ПриСозданииНаСервере()` устанавливается значение реквизита *Признак оплаты* — в значение *Не оплачен*, если создается новый документ и в значения *Не оплачен, Оплачен частично*, либо *Оплачен полностью* — если открывается ранее записанный документ. Проверка выполняется при условии, что признак оплаты не равен значению *Оплачен полностью*.
