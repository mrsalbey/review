
## Планы видов расчетов

1. Начисления.
	- [ ] Выведен в интерфейс раздела *Персонал*.
	- [ ] Добавлены предопределенные вида расчета *Оклад* и *Больничный*. 
	- [ ] На форме реквизит *Формула расчета* предопределенных элементов недоступен для ручного изменения. 

## Справочники

1. Графики работы сотрудников.
	- [ ] Элемент справочника записывается перед формированием движений по регистру сведений *Графики работы предприятия*.

## Документы

1. Начисление зарплаты.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Реквизиты шапки документа выровнены по левому краю.
2. Больничный лист.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Начисление *Больничный* вытесняет начисление оклада по периоду.
3. Премия.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.

## Отчеты
1. Отчет по начислению зарплаты.
	- [ ] Формируются колонки по периоду *Месяц*. Формат заголовка соответствует макету.
	- [ ] На форму выведены отборы по сотруднику и виду расчета.
