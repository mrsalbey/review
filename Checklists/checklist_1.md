## Документы

1. Общие замечания ко всем документам.
	- [ ] Реквизит *Комментарий* имеет тип *Строка* неограниченной длины.

	- [ ] Для реквизита *Клиент* установлен отбор по типу контрагента *Клиент*.

	- [ ] Реквизиты табличной части обязательны для заполнения.

	- [ ] Табличная часть называется *Услуги*.
3. Реализация товаров и услуг.

	- [ ] Для реквизита *Клиент* НЕ установлен отбор по типу контрагента *Клиент*.
	- [ ] Табличные части называются *Услуги* и *Товары*.
	- [ ] Для реквизита табличной части *Услуги* установлен отбор по типу номенклатуры *Услуга*.
	- [ ] Для реквизита табличной части *Товар* установлен отбор по типу номенклатуры — *Товар* и *Материал*.
