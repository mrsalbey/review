# Документы

1. Общие замечания ко всем документам.

2. Запись клиента.
	- [ ] Заполняется цена для реквизита табличной части *Стоимость* из регистра сведений на дату документа.
3. Реализация товаров и услуг.
	- [ ] Заполняются цены для услуги и товара из регистра сведений на дату документа. После изменения цены пересчитывается сумма по строке.
	- [ ] Расчет суммы документа выполняется при любом изменении табличных частей.
	- [ ] Расчет суммы по строке в табличной части *Товары* выполняется при изменении количества и цены номенклатуры.
	- [ ] Реквизит *Сумма* табличной части *Товары* не доступен для ручного изменения.
	- [ ] Реквизит *Сумма* табличной части *Услуги* доступен для ручного изменения.
4. Поступление товаров.
	- [ ] Расчет суммы документа выполняется при любом изменении табличной части.
	- [ ] Расчет суммы по строке в табличной части *Товары* выполняется при изменении количества и цены номенклатуры.
	- [ ] Реквизит *Сумма* табличной части *Товары* не доступен для ручного изменения.
5. Перемещение товаров.
	- [ ] Реквизиты на форме отображаются как *Склад-отправитель* и *Склад-получатель*.
	- [ ] Для реквизита табличной части *Товар* установлен отбор по типу номенклатуры *Товар* и *Материал*.
	- [ ] Документ формирует два движения по регистру *Товары на складах* на каждую строку табличной части в одном цикле, сначала с видом *Расход*, затем — *Приход*.
	- [ ] Документ добавлен в состав функциональной опции *Использовать склады*.
