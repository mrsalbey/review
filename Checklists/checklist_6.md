## Документы

1. Поступление на расчетный счет.
	- [ ] На форму документы выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Документ вводится на основании документа *Реализация товаров и услуг*, *Поступление товаров* и *Поступление услуг*, при этом заполняются реквизиты *Вид операции, Плательщик, Документ-основание и Сумма документа*.
	- [ ] Для реквизита *Договор контрагента* настроена связь со справочником-владельцем.
	- [ ] Реквизит *Автор документа* заполняется при создании документа при условии, что он не заполнен. Допускается заполнять реквизит в процедуре `ОбработкаЗаполнения()` модуля объекта. Реквизит недоступен для ручного изменения на форме.
	- [ ] При создании документа заполняется значение по умолчанию для реквизита *Вид операции*. При открытии документа устанавливается видимость необходимых реквизитов.
	- [ ] Документ не проводится и не создает движения по регистрам при нулевом значении реквизита *Сумма документа*.
	- [ ] При изменении вида операции на значения *Взнос наличными* или *Оплата по банковским картам* и при заполненном значении реквизита *Договор контрагента* задается вопрос на подтверждение очищения договора. При отказе возвращается предыдущее значение реквизита.
	- [ ] При изменении реквизита *Плательщик* с типом контрагента *Поставщик* на другого контрагента с таким же типом и при заполненном значении договора, договор очищается. При отказе возвращается предыдущее значение реквизита.
	- [ ] При изменении реквизита *Плательщик* со типом контрагента *Поставщик* на контрагента с типом *Клиент* и заполненном значении договора, задается вопрос на подтверждение очищения договора. При отказе возвращается предыдущее значение реквизита.
	- [ ] При многократном проведении документа движения регистров замещают предыдущие записи.
	- [ ] При проведении документа формируется движение с видом *Приход* по регистру *Денежные средства*, все измерения и ресурсы регистра заполнены.
	- [ ] НЕ формируется бухгалтерская проводка при значении вида операции *Взнос наличными*.
	- [ ] Перед формированием движений по регистрам не записываются пустые наборы регистров накопления.
	- [ ] Добавлен реквизит *Касса*, который отображается при виде операции *Взнос наличными* под реквизитом *Расчетный счет*.
2. Списание с расчетного счета.
	- [ ] При изменении вида операции на значения *Снятие наличных в кассу*, *Перечисление подотчетному лицу* или *Перечисление заработной платы* и при заполненном значении реквизита *Договор контрагента* задается вопрос на подтверждение очищения договора. При отказе следует возвращать предыдущее значение реквизита.
	- [ ] При изменении реквизита *Получатель* с типом контрагента *Поставщик* на другого контрагента с таким же типом и при заполненном значении договора, договор очищается. При отказе возвращается предыдущее значение реквизита.
	- [ ] При изменении реквизита *Получатель* со типом контрагента *Поставщик* на контрагента с типом *Клиент* и заполненном значении договора, задается вопрос на подтверждение очищения договора. При отказе возвращается предыдущее значение реквизита.
	- [ ] НЕ формируется бухгалтерская проводка при значении вида операции *Снятие наличных в кассу*.
	- [ ] Отсутствует контроль отрицательных остатков по регистру *Денежные средства*.
3. Поступление денежных средств.
	- [ ] Добавлен реквизит *Расчетный счет*, который размещен на форме под реквизитом *Касса*.
	- [ ] Оплата по карте доступна только для операции _Оплата от покупателя_, следовательно, ограничена доступность данного реквизита для других операций и принудительно устанавливается тип операции _Наличные_ при выборе вида операции отличающегося от _Оплаты от покупателя_.
4. Поступление услуг.
	- [ ] Движения по регистру *Учет затрат* сворачиваются по статье затрат при условии, когда две услуги имеют одинаковую статью затрат, но разные счета учета.

## Планы счетов

1. Хозрасчетный.
	- [ ] Наименование плана счетов — *Хозрасчетный*.

## Справочники

1. Номенклатура.
	- [ ] При создании нового элемента справочника тип номенклатуры устанавливается в значение по умолчанию — *Товары* и счет бухгалтерского учета — *41*. При изменении вида номенклатуры устанавливаются счета по умолчанию. Ограничена возможность ввода счетов для номенклатуры.
