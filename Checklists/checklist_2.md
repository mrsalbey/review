## Справочники

1. Организации
	- [ ] Реквизит *Тип организации* заполняется значением по умолчанию.
	- [ ] Созданы форма элемента и форма списка справочника. Процедуры формы элемента привязаны к соответствующим событиям формы.
2. Породы питомцев.
	- [ ] Реквизит *Вид питомца* заполняется значением по умолчанию.
	- [ ] Форма списка справочника отображается в виде дерева.
3. Контрагенты.
	- [ ] Реквизит *Тип контрагента* заполняется значением по умолчанию.
	- [ ] Созданы форма элемента и форма списка справочника. Процедуры формы элемента привязаны к соответствующим событиям формы.
	- [ ] Табличная часть на форме имеет заголовок *Питомцы*.
	- [ ] Форма списка справочника отображается в виде дерева.
	- [ ] Заголовок для стандартного реквизита *Наименование* отображается как *Ф.И.О.* для контрагентов с типом *Клиент*, и как *Наименование* для контрагентов с типом *Поставщик*.
	- [ ] Реквизит *Комментарий* равномерно растягивается во всю ширину формы при увеличении формы до полноэкранного режима.
4. Договоры контрагентов.
	- [ ] Созданы форма элемента и форма списка справочника. Процедуры формы элемента привязаны к соответствующим событиям формы.
	- [ ]  В предопределенной процедуре `ПриОткрытии()` не изменяется значение стандартного реквизита *Наименование*.
	- [ ] Реквизит *Наименование* не доступен для ручного изменения и соответствует шаблону *№ 123 от 14.01.2023 г.*.
	- [ ] В процедуре формирования наименования договора отсутствуют нефункциональные условия для заполнения значения реквизита *Наименование*.
5. Номенклатура.
	- [ ] Реквизит *Тип номенклатуры* заполняется значением по умолчанию.
	- [ ] Созданы форма элемента и форма списка справочника.
6. Сотрудники.
	- [ ] Созданы форма элемента, форма выбора и форма списка справочника. Процедуры формы элемента привязаны к соответствующим событиям формы.
	- [ ] В предопределенной процедуре `ПриОткрытии()` не изменяется значение реквизита *Наименование*.
	- [ ] Реквизит *Наименование* не доступен для ручного изменения и формируется автоматически при изменении соответствующих реквизитов. В начале и в конце наименования отсутствуют пробелы. А также, отсутствуют нефункциональные условия.
7. Пользователи.
	- [ ] Создана отдельная роль для пользователей с отсутствием прав на добавление новых пользователей. Роль имеет полные права на остальные объекты метаданных.

## Документы

1. Запись клиента.
	- [ ]  Созданы форма документа и форма списка. Форма списка документа выведена на начальную страницу и имеет заголовок *Журнал записи клиентов*.
	- [ ] Реквизиты шапки документа выровнены по левому краю. Реквизиты  *Должность* и *Номер телефона* выровнены по горизонтали с реквизитами *Сотрудник* и *Клиент* соответственно.
	- [ ] Реквизиты подвала документа равномерно растягиваются при увеличении формы до полноэкранного размера.
	- [ ] Реквизит *Ответственный* заполняется при создании документа и недоступен для ручного изменения.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Движение по регистру *Заказы клиентов* формируется одной записью на итоговую сумму услуг и записывается в ресурс *Сумма (план)* . Движение НЕ формируется при незаполненной табличной части *Услуги*.
	- [ ] При многократном проведении документа движения регистров замещают предыдущие записи.
2. Реализация товаров и услуг.
	- [ ] Созданы форма документа и форма списка.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Реквизиты подвала документа равномерно растягиваются при увеличении формы до полноэкранного размера.
	- [ ] Реквизит *Ответственный* заполняется при создании документа и недоступен для ручного изменения.
	- [ ]  Реквизит *Сумма документа* рассчитывается при записи документа и недоступен для ручного изменения.
	- [ ] В подвале табличных частей отображается итог по колонке *Сумма* и префикс *Итого:*.
	- [ ] Формирование движений по регистрам оптимизировано и производится за два цикла. Движение по регистру *Заказы клиентов* формируется одной записью при условии, что документ введен на основании записи клиента. Сумма услуг записывается в ресурс *Сумма (факт)*.
	- [ ] Формирование печатной формы оптимизировано, не выводится шапка для незаполненных табличных частей.
	- [ ] При многократном проведении документа движения регистров замещают предыдущие записи.
3. Поступление товаров.
	- [ ] Созданы форма документа и форма списка.
	- [ ] На форму выведены навигационные ссылки для просмотра движений документа по регистрам.
	- [ ] Реквизиты подвала документа равномерно растягиваются при увеличении формы до полноэкранного размера.
	- [ ] Реквизит *Ответственный* заполняется при создании документа и недоступен для ручного изменения.
	- [ ] Реквизит *Сумма документа* рассчитывается при записи документа и недоступен для ручного изменения.
	- [ ] В подвале табличной части отображается итог по колонке *Сумма* и префикс *Итого:*.
	- [ ] При многократном проведении документа движения регистров замещают предыдущие записи.
