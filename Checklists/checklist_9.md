## Задачи

1. Задача исполнителя.
	- [ ] В списке всех задач (в разделе *Настройки* - *Бизнес-процессы и Задачи)* отражается перечень всех задач, по всем исполнителям, включая завершенные. На начальной странице выведен список невыполненных задач по роли текущего пользователя.
	- [ ] Реквизит *Получено согласие* имеет тип *Булево*.
	- [ ] Реквизит *Описание задачи* соответствует техническому заданию, в частности, содержит наименование и номер телефона клиента.
	- [ ] При отсутствии согласия помечается на удаление пользователь —  исполнитель текущей задачи.
	- [ ] Для реквизитов адресации корректно заполнены значения измерений адресации.

## Бизнес-процессы

1. Дорегистрация пользователей.
	- [ ]  На форму выведена навигационная ссылка для просмотра задач по бизнес-процессу. 
	- [ ] Реквизит *Регистрация подтверждена* заполняется автоматически и недоступен для ручного изменения.
	- [ ] Заголовок формы просмотра карты маршрута соответствует макету, а именно, *Карта маршрута бизнес-процесса*.
	- [ ] Кнопка *Обновить* на форме просмотра карты маршрута при нажатии отображает текущее состояние бизнес-процесса.
	- [ ] Реквизиты бизнес-процесса называются *Пользователь* и *Регистрация подтверждена*.
