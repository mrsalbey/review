
## Регистры сведений

1. Цены номенклатуры поставщиков.
	- [ ] Наименование регистра задано во множественном числе.
	- [ ] Измерения регистра помечены как обязательные для заполнения.

## Документы

1. Установка цен поставщика.
	- [ ] Для реквизита *Контрагент* настроен отбор по типу контрагента *Поставщик*.
	- [ ] При наличии в табличной части двух одинаковых товаров с разными ценами не возникает ошибки записи регистра сведений. В регистр записывается наибольшая цена.
	- [ ] Реквизит *Ответственный* заполняется при создании документа при условии, что он не заполнен. Допускается заполнять реквизит в процедуре `ОбработкаЗаполнения()` модуля объекта. Реквизит недоступен для ручного изменения на форме.
	- [ ] На форму документа вынесена навигационная ссылка для просмотра движений документа по регистру сведений *Цены номенклатуры поставщиков*. Устанавливается отбор по текущему документу.
	- [ ] Заполняется реквизит *Ответственный*  при программном создании документа, либо перед записью документа *Установка цен поставщика*.
	- [ ] Реквизиты *Комментарий и Ответственный* равномерно растягиваются во всю ширину формы при увеличении ее до полноэкранного размера.
	- [ ] В форме загрузки прайс-листа для реквизита *Поставщик* установлен отбор по типу контрагента *Поставщик*.
2. Поступление товаров.
	- [ ] Реквизит табличной части *Цена* заполняется при изменении номенклатуры ценой на дату документа из регистра сведений *Цены номенклатуры поставщиков*. При определении цены накладывается отбор по реквизиту *Поставщик*.
	- [ ] На форме документа реализована команда *Обновить цены*, по нажатию которой обновляются цены номенклатуры в табличной части. При изменении цены пересчитывается сумма по строке, а также сумма документа.
	- [ ] Перед обновлением цены задается вопрос пользователю.
	- [ ] Если цен в регистре нет, то по этим позициям номенклатуры цена изменяется на 0 (ноль).
3. Поступление услуг.
	- [ ] Реквизит табличной части *Цена* заполняется при изменении номенклатуры ценой на дату документа из регистра сведений *Цены номенклатуры поставщиков*. При определении цены накладывается отбор по реквизиту *Поставщик*.
	- [ ] На форме документа реализована команда *Обновить цены*, по нажатию которой обновляются цены номенклатуры в табличной части. При изменении цены пересчитывается сумма по строке, а также сумма документа.
	- [ ] Перед обновлением цены задается вопрос пользователю.
	- [ ] Если цен в регистре нет, то по этим позициям номенклатуры цена изменяется на 0 (ноль).

## Обработки

1. Монитор руководителя.
	- [ ] При открытии формы заполняются значения по умолчанию: *Дата загрузки новостей* — текущая дата, *Количество новостей* — 10, *Тема поиска* — Бизнес, *Язык поиска* — Русский.
	- [ ] Константа для хранения настроек *API KEY* вынесена в интерфейс, в подсистему *Настройки*.
	- [ ] В модуле формы не используется метод `Сообщить()`.
